# Attribute

## Overview

A named and typed property that holds a single piece of data.

## Composition

* Name
* Datatype
* Value

Datatype is one of:

**Literal**

* boolean
* number
  * integer
  * float
* string
  * phone number
  * email address

**Object**

* object - a collection of named attributes
* list - sorted list of literals or objects

## Example

* Name = group-name
* Datatype = string
* Value = "Boston Bridge Club"
