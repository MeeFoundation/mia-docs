# Tasks: kerita

The test suite comes before the crate: groups 2 and 3 build the oracle and the corpus, and no logic of the crate is written before group 4. Every agent working on these tasks follows the rules of proposal.md, "Rules for agents and models working on this change", from the first task on.

A task that makes a scenario real is done when its test fails with the mechanism removed; each such task says how that is shown. No stress pass is owed: the crate has no concurrency, no I/O and no timing, and its tests are deterministic by construction.
